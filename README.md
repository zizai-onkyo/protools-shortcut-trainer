# Pro Tools ショートカット トレーナー（β）

Pro Tools のショートカットを、実際にキーを押して覚えるトレーニングゲームです。

- **ゲーム** → https://zizai-onkyo.github.io/protools-shortcut-trainer/
- **捕捉テスター** → https://zizai-onkyo.github.io/protools-shortcut-trainer/keytest.html
  （そのMacでどのショートカットがブラウザに届くかを実測するツール）

## 遊び方

**Chrome または Edge** で開いてください。全画面＋ Keyboard Lock API により、
通常はブラウザに奪われる ⌘+N などのキーも判定できます。

機能名が表示されるので、対応するショートカットを実際に押します。
1ラウンド20問、1問8秒。速く押すほど高得点、連続正解でコンボ倍率がかかります。

- 出題範囲：★基本 / 全部 / 苦手だけ / カテゴリ別
- 間違えた項目は「苦手リスト」に蓄積され、重点的に復習できます
- 重要度 ◎ の項目が多めに出題されます

## 更新方法

問題データは別リポジトリの `shortcuts.csv` から生成しています。
更新するときは、生成した HTML をこのリポジトリにコピーして push してください。
